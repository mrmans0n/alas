# Design rubric

Runner-only, never send to judges.

Judges score each app on these categories, 0 to 10, and give specific findings
per app. Each finding names the screen and says what is wrong.

## Categories

1. **Hierarchy**: the eye lands on what matters first; primary, secondary and
   tertiary information are told apart at a glance.
2. **Typography**: size, weight and line-height steps are few and deliberate;
   text reads comfortably at its size.
3. **Colour and contrast**: text and controls are legible; colour carries
   meaning (state, attention) rather than decoration; the palette has
   character without noise.
4. **Spacing**: rhythm is consistent; related things sit together, unrelated
   things have room; alignment is exact.
5. **Iconography**: icons share one style, weight and size grid; each is
   recognisable without its label.
6. **Consistency**: the same thing looks the same everywhere, in both themes.
7. **Density fit**: the amount shown per screen suits the job; neither cramped
   nor wasteful.

## How references are used

An app with the same job as Alas (Claude) is compared on layout and feel:
structure, placement, proportions, and the overall impression.

Other apps (Pixelmator Pro, Craft, Loop) are compared on feel only: hierarchy,
restraint, material. They do the job differently, so never judge Alas's layout
against theirs.

The judge prompt never states these roles. They tell the runner how to read
findings: discard a layout finding that comes from a feel-only reference.

## Reading scores

- Scores are relative within a round. A reference app's score moving between
  rounds is a drift check on the judges, not news about the reference.
- Weight findings over numbers. Several judges naming the same specific problem
  beats any score.
- The owner's judgement overrides every score.
