# Device panel, phase 1: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Device tab in the right pane that shows a live iOS Simulator the user can boot, tap, drag, and type into, with no Node or other runtime dependency.

**Architecture:** serve-sim's Swift capture and input code is vendored unmodified into a local SwiftPM package (`ThirdParty/serve-sim-native`) behind one public class, `AlasSimulatorSession`. An XPC service, `AlasSimService.xpc`, links it, loads the private simulator frameworks, and sends each frame's `IOSurface` to Alas. Alas lists and boots simulators with `xcrun simctl`, shows frames on an `AVSampleBufferDisplayLayer`, and sends touches and keys back over the same connection. The pure decisions (device list order, pane status, click mapping, key mapping, stream counting) live in AlasCore with Swift Testing coverage.

**Tech stack:** Swift 6 (app and service), Swift 5 language mode (vendored package), SwiftUI and AppKit, NSXPCConnection, AVFoundation, Swift Testing, xcodegen.

**Spec:** `docs/plans/2026-11-04-device-panel-design.md`

## Review focus

Inputs the spec implies that are easy to get wrong. Each has a test or a manual check in the task named.

1. Switching worktrees while the Device tab is open: SwiftUI can create the new pane's screen before it removes the old one, so the old one's stop must not end the stream the new one just joined. Task 3, `aStreamStopsOnlyWhenItsLastScreenLeaves`.
2. The chosen simulator is shut down or deleted outside Alas (Xcode, `simctl`). The pane shows the shut-down state or falls back to a booted device, never a frozen frame. Task 2, the "shut down outside Alas" and "deleted choice" rows of `statusFollowsTheDeviceListAndTheChoice`.
3. A click in the letterbox bars beside the screen does nothing, and a drag that leaves the screen still ends with a touch-up at the edge. Task 3, `clicksMapOntoTheFittedScreen` and `dragsOutsideTheScreenClampToItsEdge`.
4. Xcode missing, or `xcode-select` pointing at the Command Line Tools: the pane shows simctl's error instead of an empty list. Task 2, the "simctl error" row; Task 7, step 5.
5. The XPC service crashes mid-stream: the screen says the stream stopped and Retry brings it back. Task 7, step 4 (`kill` the service).

```bash
#!/usr/bin/env bash
# Re-vendors serve-sim's native Swift from expo/expo-device-hub at one commit.
# Copies StreamingPolicy and CoreDeviceShim whole, and the SimNative files
# listed in vendored-files.txt. AlasSimulatorSession.swift is ours and is
# left alone.
set -euo pipefail

commit="${1:?usage: sync.sh <expo-device-hub commit>}"
here="$(cd "$(dirname "$0")" && pwd)"
work="$(mktemp -d)"
trap 'rm -rf "$work"' EXIT

git clone -q --filter=blob:none --no-checkout --sparse \
  https://github.com/expo/expo-device-hub.git "$work/repo"
git -C "$work/repo" sparse-checkout set --no-cone \
  '/packages/serve-sim/packages/serve-sim/Sources/' \
  '/packages/serve-sim/LICENSE' \
  '/packages/serve-sim/NOTICE'
git -C "$work/repo" checkout -q "$commit"

src="$work/repo/packages/serve-sim/packages/serve-sim/Sources"
mkdir -p "$here/Sources/ServeSimCore"
rm -rf "$here/Sources/StreamingPolicy" "$here/Sources/CoreDeviceShim"
cp -R "$src/StreamingPolicy" "$src/CoreDeviceShim" "$here/Sources/"
while read -r name; do
  [ -n "$name" ] || continue
  cp "$src/SimNative/$name.swift" "$here/Sources/ServeSimCore/$name.swift"
done < "$here/vendored-files.txt"
cp "$work/repo/packages/serve-sim/LICENSE" "$work/repo/packages/serve-sim/NOTICE" "$here/"
printf '%s\n' "$commit" > "$here/UPSTREAM_COMMIT"
echo "Vendored serve-sim native code at $commit"
```

- [ ] **Step 5: Write the facade.** `ThirdParty/serve-sim-native/Sources/ServeSimCore/AlasSimulatorSession.swift`. `HIDInjector` is an actor, so input goes through one `AsyncStream` to keep each touch's begin, moves and end in order:

```swift
import CoreVideo
import Foundation

/// Alas's entry point into the vendored serve-sim code: one booted
/// simulator's screen and input. Not from upstream; sync.sh leaves it alone.
public final class AlasSimulatorSession: @unchecked Sendable {
    public enum TouchPhase: String, Sendable {
        case begin, move, end
    }

    private enum Input: Sendable {
        case touch(TouchPhase, x: Double, y: Double)
        case key(usage: UInt32, down: Bool)
        case button(String)
    }

    public let udid: String
    private let capture = FrameCapture()
    private let hid = HIDInjector()
    /// `HIDInjector` is an actor. Input goes through one stream so a touch's
    /// begin, moves and end reach it in the order they were sent.
    private let input: AsyncStream<Input>.Continuation

    public init(udid: String) {
        self.udid = udid
        let (stream, continuation) = AsyncStream.makeStream(of: Input.self)
        input = continuation
        Task { [hid] in
            for await event in stream {
                switch event {
                case .touch(let phase, let x, let y):
                    await hid.sendTouch(type: phase.rawValue, x: x, y: y, screenWidth: 0, screenHeight: 0)
                case .key(let usage, let down):
                    await hid.sendKey(type: down ? "down" : "up", usage: usage)
                case .button(let name):
                    await hid.sendButton(button: name, deviceUDID: udid)
                }
            }
        }
    }

    deinit {
        input.finish()
    }

    /// Starts capture, then input. `onFrame` runs on a capture queue with an
    /// IOSurface-backed `420v` copy of each new frame, taken from a pool.
    public func start(onFrame: @escaping @Sendable (CVPixelBuffer) -> Void) async throws {
        try await capture.start(deviceUDID: udid) { pixelBuffer, _, _, _ in
            onFrame(pixelBuffer)
        }
        try await hid.setup(deviceUDID: udid)
    }

    public func stop() async {
        input.finish()
        await capture.stop()
    }

    /// `x` and `y` run from 0 to 1 across the portrait screen, from its top left.
    public func touch(_ phase: TouchPhase, x: Double, y: Double) {
        input.yield(.touch(phase, x: x, y: y))
    }

    /// `usage` is a USB HID keyboard usage (page 0x07).
    public func key(usage: UInt32, down: Bool) {
        input.yield(.key(usage: usage, down: down))
    }

    /// One of serve-sim's button names: `home`, `lock`, `siri`,
    /// `side_button`, `app_switcher`, `swipe_home`.
    public func button(_ name: String) {
        input.yield(.button(name))
    }
}
```

```swift
import Foundation

/// One iOS simulator from `xcrun simctl list devices --json`.
public struct SimulatorDevice: Equatable, Sendable, Identifiable {
    public enum State: Equatable, Sendable {
        case booted, booting, shutdown, shuttingDown
        case other(String)

        init(simctl value: String) {
            switch value {
            case "Booted": self = .booted
            case "Booting": self = .booting
            case "Shutdown": self = .shutdown
            case "Shutting Down": self = .shuttingDown
            default: self = .other(value)
            }
        }
    }

    public let udid: String
    public let name: String
    /// For example "iOS 26.5".
    public let runtimeName: String
    public let state: State
    public var id: String { udid }

    public init(udid: String, name: String, runtimeName: String, state: State) {
        self.udid = udid
        self.name = name
        self.runtimeName = runtimeName
        self.state = state
    }
}

public enum SimulatorDeviceList {
    private struct Listing: Decodable {
        struct Device: Decodable {
            let udid: String
            let name: String
            let state: String
            let isAvailable: Bool?
        }
        let devices: [String: [Device]]
    }

    /// The available iOS simulators in simctl's JSON: booted first, then the
    /// newest runtime, then by name.
    public static func parse(_ json: Data) throws -> [SimulatorDevice] {
        let listing = try JSONDecoder().decode(Listing.self, from: json)
        var rows: [(version: [Int], device: SimulatorDevice)] = []
        for (runtime, devices) in listing.devices {
            guard let parts = runtimeParts(runtime), parts.platform == "iOS" else { continue }
            let runtimeName = "iOS " + parts.version.map(String.init).joined(separator: ".")
            for device in devices where device.isAvailable == true {
                rows.append((parts.version, SimulatorDevice(
                    udid: device.udid, name: device.name, runtimeName: runtimeName,
                    state: .init(simctl: device.state)
                )))
            }
        }
        rows.sort { a, b in
            let aBooted = a.device.state == .booted
            let bBooted = b.device.state == .booted
            if aBooted != bBooted { return aBooted }
            if a.version != b.version { return b.version.lexicographicallyPrecedes(a.version) }
            if a.device.name != b.device.name { return a.device.name < b.device.name }
            return a.device.udid < b.device.udid
        }
        return rows.map(\.device)
    }

    /// `com.apple.CoreSimulator.SimRuntime.iOS-26-5` is `("iOS", [26, 5])`.
    static func runtimeParts(_ identifier: String) -> (platform: String, version: [Int])? {
        guard let last = identifier.split(separator: ".").last else { return nil }
        let parts = last.split(separator: "-")
        guard parts.count >= 2 else { return nil }
        let version = parts.dropFirst().compactMap { Int($0) }
        guard version.count == parts.count - 1 else { return nil }
        return (String(parts[0]), version)
    }
}
```

```swift
/// What the Device tab shows, from the latest device list and the user's choice.
public enum DevicePaneStatus: Equatable, Sendable {
    case loading
    /// simctl failed. The message is its error output.
    case unavailable(String)
    case noDevices
    /// Nothing chosen and nothing booted.
    case choose
    case shutDown(SimulatorDevice)
    case booting(SimulatorDevice)
    case streaming(SimulatorDevice)

    public var device: SimulatorDevice? {
        switch self {
        case .shutDown(let device), .booting(let device), .streaming(let device): device
        case .loading, .unavailable, .noDevices, .choose: nil
        }
    }

    /// A chosen device that no longer exists falls back to the first booted
    /// one. A chosen device that is shut down stays chosen, so the pane offers
    /// to boot it instead of jumping to another simulator.
    public static func resolve(
        devices: [SimulatorDevice]?,
        listError: String?,
        selectedUDID: String?,
        bootingUDIDs: Set<String>
    ) -> DevicePaneStatus {
        if let listError { return .unavailable(listError) }
        guard let devices else { return .loading }
        guard !devices.isEmpty else { return .noDevices }
        let chosen = selectedUDID.flatMap { udid in devices.first { $0.udid == udid } }
            ?? devices.first { $0.state == .booted }
        guard let chosen else { return .choose }
        if bootingUDIDs.contains(chosen.udid) || chosen.state == .booting { return .booting(chosen) }
        return chosen.state == .booted ? .streaming(chosen) : .shutDown(chosen)
    }
}
```

```swift
import AlasPlatform
import Foundation

public struct SimulatorControlError: Error, LocalizedError, Equatable {
    public let message: String

    init(_ result: ProcessResult) {
        let output = result.stderr.trimmingCharacters(in: .whitespacesAndNewlines)
        message = output.isEmpty ? "simctl exited with status \(result.exitCode)" : output
    }

    public var errorDescription: String? { message }
}

/// Lists and boots simulators with `xcrun simctl`, which is public API.
/// Capture and input go through AlasSimService instead.
public enum SimulatorControl {
    private static let xcrun = "/usr/bin/xcrun"

    public static func devices() async throws -> [SimulatorDevice] {
        let result = try await Process.run(xcrun, args: ["simctl", "list", "devices", "--json"])
        guard result.exitCode == 0 else { throw SimulatorControlError(result) }
        return try SimulatorDeviceList.parse(Data(result.stdout.utf8))
    }

    /// Returns once the device has finished booting.
    public static func boot(udid: String) async throws {
        let boot = try await Process.run(xcrun, args: ["simctl", "boot", udid])
        // A device that booted in the meantime answers
        // "Unable to boot device in current state: Booted".
        guard boot.exitCode == 0 || boot.stderr.contains("current state: Booted") else {
            throw SimulatorControlError(boot)
        }
        let status = try await Process.run(xcrun, args: ["simctl", "bootstatus", udid, "-b"], timeout: 300)
        guard status.exitCode == 0 else { throw SimulatorControlError(status) }
    }
}
```

```swift
/// A point on a simulator screen, 0 to 1 across each axis from the top left.
public struct DeviceScreenPoint: Equatable, Sendable {
    public let x: Double
    public let y: Double

    public init(x: Double, y: Double) {
        self.x = x
        self.y = y
    }
}

/// Where a simulator screen sits when it is fitted, centered, into a view
/// (top-left origin), and where a point in the view lands on it.
public struct DeviceScreenGeometry: Sendable {
    public let screenWidth: Double
    public let screenHeight: Double
    public let viewWidth: Double
    public let viewHeight: Double

    public init(screenWidth: Double, screenHeight: Double, viewWidth: Double, viewHeight: Double) {
        self.screenWidth = screenWidth
        self.screenHeight = screenHeight
        self.viewWidth = viewWidth
        self.viewHeight = viewHeight
    }

    /// The point on the screen, or nil in the bars beside it.
    public func normalized(x: Double, y: Double) -> DeviceScreenPoint? {
        guard let point = unclamped(x: x, y: y),
              (0...1).contains(point.x), (0...1).contains(point.y) else { return nil }
        return point
    }

    /// The point on the screen, pulled to the nearest edge when outside, so
    /// a drag that leaves the screen still ends on it.
    public func clamped(x: Double, y: Double) -> DeviceScreenPoint? {
        guard let point = unclamped(x: x, y: y) else { return nil }
        return DeviceScreenPoint(x: min(max(point.x, 0), 1), y: min(max(point.y, 0), 1))
    }

    private func unclamped(x: Double, y: Double) -> DeviceScreenPoint? {
        guard screenWidth > 0, screenHeight > 0, viewWidth > 0, viewHeight > 0 else { return nil }
        let scale = min(viewWidth / screenWidth, viewHeight / screenHeight)
        let width = screenWidth * scale
        let height = screenHeight * scale
        let originX = (viewWidth - width) / 2
        let originY = (viewHeight - height) / 2
        return DeviceScreenPoint(x: (x - originX) / width, y: (y - originY) / height)
    }
}
```

- [ ] **Step 7: Implement the subscriptions.** `Packages/AlasCore/Sources/AlasFeatures/Devices/StreamSubscriptions.swift`:

```swift
/// Counts the screens watching each simulator, so a stream starts with its
/// first screen and stops with its last.
public struct StreamSubscriptions: Sendable {
    public enum Change: Equatable, Sendable {
        case start, stop, none
    }

    private var counts: [String: Int] = [:]

    public init() {}

    public mutating func add(_ udid: String) -> Change {
        counts[udid, default: 0] += 1
        return counts[udid] == 1 ? .start : .none
    }

    public mutating func remove(_ udid: String) -> Change {
        guard let count = counts[udid] else { return .none }
        guard count > 1 else {
            counts[udid] = nil
            return .stop
        }
        counts[udid] = count - 1
        return .none
    }

    /// The watched devices, sorted.
    public var active: [String] { counts.keys.sorted() }
}
```

```swift
@objc protocol SimServiceProtocol {
    /// Streams `udid` to the connection's exported `SimFrameSink`. Replies nil
    /// once frames flow, or an error message.
    func startStream(udid: String, reply: @escaping @Sendable (String?) -> Void)
    func stopStream(udid: String)
    /// `phase` is `begin`, `move` or `end`. `x` and `y` run from 0 to 1 from

    func key(udid: String, usage: UInt32, down: Bool)
    /// A serve-sim button name, such as `home`.
    func button(udid: String, name: String)
}

@objc protocol SimFrameSink {
    /// A new frame: an IOSurface-backed `420v` buffer from the service's pool.
```

```swift
import CoreVideo
import Foundation
import IOSurface
import ServeSimCore

/// Accepts Alas's connection and gives it a handler for its sessions.
final class SimServiceListenerDelegate: NSObject, NSXPCListenerDelegate {
    func listener(_ listener: NSXPCListener, shouldAcceptNewConnection connection: NSXPCConnection) -> Bool {
        connection.exportedInterface = NSXPCInterface(with: SimServiceProtocol.self)
        connection.remoteObjectInterface = NSXPCInterface(with: SimFrameSink.self)
        let handler = SimServiceHandler(connection: connection)
        connection.exportedObject = handler
        connection.invalidationHandler = { handler.stopAll() }
        connection.resume()
        return true
    }
}

/// The simulator sessions one Alas connection started, by UDID.
final class SimServiceHandler: NSObject, SimServiceProtocol, @unchecked Sendable {
    private let lock = NSLock()
    private var sessions: [String: AlasSimulatorSession] = [:]
    private weak var connection: NSXPCConnection?

    init(connection: NSXPCConnection) {
        self.connection = connection
    }

    func startStream(udid: String, reply: @escaping @Sendable (String?) -> Void) {
        let session = AlasSimulatorSession(udid: udid)
        let previous = lock.withLock { () -> AlasSimulatorSession? in
            defer { sessions[udid] = session }
            return sessions[udid]
        }
        nonisolated(unsafe) let sink = connection?.remoteObjectProxy as? SimFrameSink
        Task {
            await previous?.stop()
            do {
                try await session.start { pixelBuffer in
                    guard let surface = CVPixelBufferGetIOSurface(pixelBuffer)?.takeUnretainedValue() else { return }
                    sink?.frame(udid: udid, surface: surface as IOSurface)
                }
                reply(nil)
            } catch {
                self.lock.withLock {
                    if self.sessions[udid] === session { self.sessions[udid] = nil }
                }
                reply(error.localizedDescription)
            }
        }
    }

    func stopStream(udid: String) {
        guard let session = lock.withLock({ sessions.removeValue(forKey: udid) }) else { return }
        Task { await session.stop() }
    }

    func touch(udid: String, phase: String, x: Double, y: Double) {
        guard let phase = AlasSimulatorSession.TouchPhase(rawValue: phase) else { return }
        session(udid)?.touch(phase, x: x, y: y)
    }

    func key(udid: String, usage: UInt32, down: Bool) {
        session(udid)?.key(usage: usage, down: down)
    }

    func button(udid: String, name: String) {
        session(udid)?.button(name)
    }

    func stopAll() {
        let all = lock.withLock { () -> [AlasSimulatorSession] in
            defer { sessions.removeAll() }
            return Array(sessions.values)
        }
        Task { for session in all { await session.stop() } }
    }

    private func session(_ udid: String) -> AlasSimulatorSession? {
        lock.withLock { sessions[udid] }
    }
}
```

```swift
import AlasCore
import Foundation
import IOSurface

/// Alas's side of AlasSimService: one XPC connection, with each device's
/// frames fanned out to the screens showing it.
@MainActor
final class SimulatorStreamClient {
    private struct Screen {
        let onFrame: @MainActor (IOSurface) -> Void
        let onStop: @MainActor (String) -> Void
    }

    private var connection: NSXPCConnection?
    private var subscriptions = StreamSubscriptions()
    private var screens: [String: [UUID: Screen]] = [:]

    func subscribe(
        udid: String,
        onFrame: @escaping @MainActor (IOSurface) -> Void,
        onStop: @escaping @MainActor (String) -> Void
    ) -> UUID {
        let token = UUID()
        screens[udid, default: [:]][token] = Screen(onFrame: onFrame, onStop: onStop)
        if subscriptions.add(udid) == .start { start(udid) }
        return token
    }

    func unsubscribe(udid: String, token: UUID) {
        screens[udid]?[token] = nil
        if screens[udid]?.isEmpty == true { screens[udid] = nil }
        if subscriptions.remove(udid) == .stop { service()?.stopStream(udid: udid) }
    }

    func touch(udid: String, phase: String, point: DeviceScreenPoint) {
        service()?.touch(udid: udid, phase: phase, x: point.x, y: point.y)
    }

    func key(udid: String, usage: UInt32, down: Bool) {
        service()?.key(udid: udid, usage: usage, down: down)
    }

    func button(udid: String, name: String) {
        service()?.button(udid: udid, name: name)
    }

    fileprivate func deliver(udid: String, surface: IOSurface) {
        screens[udid]?.values.forEach { $0.onFrame(surface) }
    }

    private func stopped(udid: String, reason: String) {
        screens[udid]?.values.forEach { $0.onStop(reason) }
    }

    private func start(_ udid: String) {
        service()?.startStream(udid: udid) { [weak self] error in
            guard let error else { return }
            DispatchQueue.main.async {
                MainActor.assumeIsolated { self?.stopped(udid: udid, reason: error) }
            }
        }
    }

    /// The service crashed or was killed. launchd starts it again on the next
    /// message, which Retry sends.
    private func connectionInterrupted() {
        for udid in subscriptions.active {
            stopped(udid: udid, reason: "The simulator stream stopped.")
        }
    }

    private func service() -> SimServiceProtocol? {
        let connection = self.connection ?? connect()
        return connection.remoteObjectProxyWithErrorHandler { _ in } as? SimServiceProtocol
    }

    private func connect() -> NSXPCConnection {
        let connection = NSXPCConnection(serviceName: SimServiceName.bundleIdentifier)
        connection.remoteObjectInterface = NSXPCInterface(with: SimServiceProtocol.self)
        connection.exportedInterface = NSXPCInterface(with: SimFrameSink.self)
        connection.exportedObject = FrameSinkBridge(client: self)
        connection.interruptionHandler = { [weak self] in
            DispatchQueue.main.async {
                MainActor.assumeIsolated { self?.connectionInterrupted() }
            }
        }
        connection.invalidationHandler = { [weak self] in
            DispatchQueue.main.async {
                MainActor.assumeIsolated {
                    self?.connection = nil
                    self?.connectionInterrupted()
                }
            }
        }
        connection.resume()
        self.connection = connection
        return connection
    }
}

/// Receives frames on the XPC queue and hands them to the main actor.
private final class FrameSinkBridge: NSObject, SimFrameSink {
    private weak var client: SimulatorStreamClient?

    init(client: SimulatorStreamClient) {
        self.client = client
    }

    func frame(udid: String, surface: IOSurface) {
        DispatchQueue.main.async { [weak client] in
            MainActor.assumeIsolated { client?.deliver(udid: udid, surface: surface) }
        }
    }
```

```swift
/// A simulator's live screen. It watches the device while it is on screen,
/// turns clicks into touches and keys into HID usages.
struct DeviceScreenView: NSViewRepresentable {
    let udid: String

    }

    }

    static func dismantleNSView(_ view: DeviceScreenNSView, coordinator: ()) {
        view.detach()
    }

final class DeviceScreenNSView: NSView {
    private let displayLayer = AVSampleBufferDisplayLayer()
    private(set) var udid: String?
    private weak var client: SimulatorStreamClient?
    private var token: UUID?
    private var screenSize = CGSize.zero
    private var lastTouch: DeviceScreenPoint?
    private var heldModifiers: Set<UInt16> = []
    var onStopped: (String) -> Void = { _ in }

    override init(frame: NSRect) {
        super.init(frame: frame)
        wantsLayer = true
        layer = CALayer()
        displayLayer.videoGravity = .resizeAspect
        layer?.addSublayer(displayLayer)
    }

    required init?(coder: NSCoder) { fatalError("init(coder:) is not used") }

    override var isFlipped: Bool { true }
    override var acceptsFirstResponder: Bool { true }
    override func acceptsFirstMouse(for event: NSEvent?) -> Bool { true }

    override func layout() {
        super.layout()
        CATransaction.begin()
        CATransaction.setDisableActions(true)
        displayLayer.frame = bounds
        CATransaction.commit()
    }

    func attach(udid: String, client: SimulatorStreamClient) {
        detach()
        self.udid = udid
        self.client = client
        token = client.subscribe(
            udid: udid,
            onFrame: { [weak self] in self?.show($0) },
            onStop: { [weak self] in self?.onStopped($0) }
        )
    }

    func detach() {
        releaseHeldInput()
        if let udid, let token { client?.unsubscribe(udid: udid, token: token) }
        udid = nil
        token = nil
        screenSize = .zero
        displayLayer.sampleBufferRenderer.flush(removingDisplayedImage: true, completionHandler: nil)
    }

    // MARK: Frames

    private func show(_ surface: IOSurface) {
        screenSize = CGSize(width: surface.width, height: surface.height)
        var unmanaged: Unmanaged<CVPixelBuffer>?
        guard CVPixelBufferCreateWithIOSurface(nil, surface as IOSurfaceRef, nil, &unmanaged) == kCVReturnSuccess,
              let pixelBuffer = unmanaged?.takeRetainedValue() else { return }
        var format: CMVideoFormatDescription?
        guard CMVideoFormatDescriptionCreateForImageBuffer(
            allocator: nil, imageBuffer: pixelBuffer, formatDescriptionOut: &format
        ) == noErr, let format else { return }
        var timing = CMSampleTimingInfo(
            duration: .invalid,
            presentationTimeStamp: CMClockGetTime(CMClockGetHostTimeClock()),
            decodeTimeStamp: .invalid
        )
        var sample: CMSampleBuffer?
        guard CMSampleBufferCreateReadyWithImageBuffer(
            allocator: nil, imageBuffer: pixelBuffer, formatDescription: format,
            sampleTiming: &timing, sampleBufferOut: &sample
        ) == noErr, let sample else { return }
        if let attachments = CMSampleBufferGetSampleAttachmentsArray(sample, createIfNecessary: true),
           CFArrayGetCount(attachments) > 0 {
            let dictionary = unsafeBitCast(CFArrayGetValueAtIndex(attachments, 0), to: CFMutableDictionary.self)
            CFDictionarySetValue(
                dictionary,
                Unmanaged.passUnretained(kCMSampleAttachmentKey_DisplayImmediately).toOpaque(),
                Unmanaged.passUnretained(kCFBooleanTrue).toOpaque()
            )
        }
        let renderer = displayLayer.sampleBufferRenderer
        if renderer.status == .failed { renderer.flush() }
        renderer.enqueue(sample)
    }

    // MARK: Touches

    private var geometry: DeviceScreenGeometry {
        DeviceScreenGeometry(
            screenWidth: screenSize.width, screenHeight: screenSize.height,
            viewWidth: bounds.width, viewHeight: bounds.height
        )
    }

    private func location(_ event: NSEvent) -> CGPoint {
        convert(event.locationInWindow, from: nil)
    }

    override func mouseDown(with event: NSEvent) {
        window?.makeFirstResponder(self)
        let point = location(event)
        guard let touch = geometry.normalized(x: point.x, y: point.y) else { return }
        send("begin", touch)
    }

    override func mouseDragged(with event: NSEvent) {
        guard lastTouch != nil else { return }
        let point = location(event)
        guard let touch = geometry.clamped(x: point.x, y: point.y) else { return }
        send("move", touch)
    }

    override func mouseUp(with event: NSEvent) {
        guard let last = lastTouch else { return }
        let point = location(event)
        send("end", geometry.clamped(x: point.x, y: point.y) ?? last)
    }

    private func send(_ phase: String, _ touch: DeviceScreenPoint) {
        guard let udid else { return }
        lastTouch = phase == "end" ? nil : touch
        client?.touch(udid: udid, phase: phase, point: touch)
    }

    // MARK: Keys

    override func keyDown(with event: NSEvent) {
        guard !event.modifierFlags.contains(.command),
              let usage = HIDKeyboardUsage.usage(forKeyCode: event.keyCode) else {
            super.keyDown(with: event)
            return
        }
        // The simulator repeats a held key itself.
        guard !event.isARepeat, let udid else { return }
        client?.key(udid: udid, usage: usage, down: true)
    }

    override func keyUp(with event: NSEvent) {
        guard !event.modifierFlags.contains(.command),
              let usage = HIDKeyboardUsage.usage(forKeyCode: event.keyCode) else {
            super.keyUp(with: event)
            return
        }
        guard let udid else { return }
        client?.key(udid: udid, usage: usage, down: false)
    }

    override func flagsChanged(with event: NSEvent) {
        guard let usage = HIDKeyboardUsage.usage(forModifierKeyCode: event.keyCode), let udid else {
            super.flagsChanged(with: event)
            return
        }
        let down = heldModifiers.insert(event.keyCode).inserted
        if !down { heldModifiers.remove(event.keyCode) }
        client?.key(udid: udid, usage: usage, down: down)
    }

    override func resignFirstResponder() -> Bool {
        releaseHeldInput()
        return super.resignFirstResponder()
    }

    /// Lifts a touch or modifier still down, so none stays stuck in the simulator.
    private func releaseHeldInput() {
        guard let udid else { return }
        if let last = lastTouch { send("end", last) }
        for keyCode in heldModifiers {
            if let usage = HIDKeyboardUsage.usage(forModifierKeyCode: keyCode) {
                client?.key(udid: udid, usage: usage, down: false)
            }
        }
        heldModifiers.removeAll()
    }
}
```

```swift
import AlasCore
import Foundation
import Observation

/// The simulators on this Mac and the one the Device tab shows. Simulators
/// belong to the Mac, so every worktree's pane shares this model.
@MainActor
@Observable
final class DevicePaneModel {
    private(set) var devices: [SimulatorDevice]?
    private(set) var listError: String?
    var selectedUDID: String?
    private(set) var bootingUDIDs: Set<String> = []
    private(set) var bootError: String?

    var status: DevicePaneStatus {
        .resolve(devices: devices, listError: listError, selectedUDID: selectedUDID, bootingUDIDs: bootingUDIDs)
    }

    func refresh() async {
        do {
            devices = try await SimulatorControl.devices()
            listError = nil
        } catch {
            listError = error.localizedDescription
        }
    }

    /// Keeps the list current while the tab is visible, so a device shut down
    /// or deleted elsewhere does not leave a frozen screen.
    func pollWhileVisible() async {
        while !Task.isCancelled {
            await refresh()
            try? await Task.sleep(for: .seconds(3))
        }
    }

    func boot(_ device: SimulatorDevice) async {
        selectedUDID = device.udid
        bootError = nil
        bootingUDIDs.insert(device.udid)
        do {
            try await SimulatorControl.boot(udid: device.udid)
        } catch {
            bootError = error.localizedDescription
        }
        await refresh()
        bootingUDIDs.remove(device.udid)
    }
}
```
